## Compilation and Testing

### Compile All Java Files
```bash
find topics -name "*.java" -exec javac {} \;
```

### Run Tests with JUnit 5
```bash
# Run all tests
java -cp ".:junit-platform-console-standalone.jar" org.junit.platform.console.ConsoleLauncher --scan-classpath

# Run specific test class
java -cp ".:junit-platform-console-standalone.jar" org.junit.platform.console.ConsoleLauncher --select-class ArraysTests
```

### Run Individual Problems
```bash
# Example: Run Two Sum
java -cp topics/arrays/TwoSum TwoSum

# Example: Run Binary Tree Level Order Traversal
java -cp topics/trees/BinaryTreeLevelOrderTraversal BinaryTreeLevelOrderTraversal
```
